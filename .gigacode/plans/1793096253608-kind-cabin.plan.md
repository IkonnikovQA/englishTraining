# Recommendations for English Trainer

## A. Content / Material Richness (приоритет #1)

### A1. Expand lesson topics per level
**Problem:** Only 3 topics at A1, 2 at A2, 2 at B1, 2 at B2. Each topic has exactly 5 questions.
**Recommendation:** Add more topics and more questions per topic.

| Level | Current topics | Suggested new topics |
|-------|---------------|---------------------|
| A1 | Greetings, Introductions, Numbers 1-20 | Colors, Family, Days & Months, Common Verbs (be/have/go), Places in City, Animals |
| A2 | Present Simple, Food & Restaurant | Past Simple (regular), Present Continuous, Adjectives & Comparison, Pronouns, Prepositions of Place/Time |
| B1 | Past Simple, Travel | Present Perfect, Future (will/going to), Modal Verbs (can/must/should), Reported Speech, Phrasal Verbs |
| B2 | Conditionals, Essay Writing | Passive Voice, Mixed Conditionals, Linkers & Discourse Markers, Vocabulary for Work, Idiomatic Expressions |

**Each new topic should have 10-15 questions** (current: 5).

### A2. Add question types
**Problem:** All questions are simple translation/multiple-choice. No variety.
**Recommendation:** Add these types (tracked via a `type` field in JSON):
- **fill-in-blank** — "I ___ (go) to school" → expected: "went"
- **sentence-building** — reorder words (handled via AI evaluation)
- **listening comprehension** — reference a phonetic transcription
- **error-correction** — "Find the mistake: 'She don't like coffee'" → expected: "doesn't"
- **matching** — match Russian to English pairs

### A3. Add audio examples for pronunciation
Store phonetic transcriptions or link to audio in settings; use Kokoro TTS to pronounce target words during lessons.

### A4. Add translations to questions
Currently questions are in Russian only. Add `translation` field for bilingual learners.

## B. Technical Improvements (приоритет #2)

### B1. Voice Chat: real microphone input
**Problem:** `_stop_recording()` falls back to `QInputDialog` — no actual microphone capture.
**Fix:** Add `PyAudio` dependency, capture audio buffer on PTT press, save as WAV, pass to Whisper.

### B2. Add pytest configuration
**Problem:** Tests use `unittest` and manual `sys.path.insert`. No `pytest.ini` / `pyproject.toml`.
**Fix:** Create `pyproject.toml` with `[tool.pytest.ini_options]`, convert tests to pytest style.

### B3. Add CI / lint config
**Problem:** No linter (flake8/ruff), no type checker (mypy), no pre-commit hooks.
**Fix:** Add `ruff.toml` or `pyproject.toml` lint config, `.pre-commit-config.yaml`.

### B4. Improve error handling in GUI
**Problem:** `MainWindow.__init__` raises on any exception — app crashes on startup with no recovery.
**Fix:** Wrap in try/except, show graceful error dialog with instructions, allow retry.

### B5. Add unit tests for GUI components
**Problem:** No tests for `LessonWidget`, `VoiceChatWidget`, `ProgressWidget`.
**Fix:** Add pytest-qt or headless tests for widget logic.

### B6. Add settings validation
**Problem:** `settings.json` schema is not validated — typos cause silent failures.
**Fix:** Add `pydantic`-based schema validation at startup.

### B7. Migrate hardcoded CSS to Qt stylesheets / QSS files
**Problem:** Inline CSS strings scattered across widgets.
**Fix:** Extract to `.qss` files, load once in `MainWindow`.
