# English Trainer — Implementation Plan

## Overview
Desktop app for learning English with local AI (Ollama + Faster-Whisper + Kokoro TTS). Fully offline, PyQt6 GUI, SQLite storage.

## Architecture
```
englishTrainer/
├── main.py                    # Entry point
├── config/
│   └── settings.json          # AI model paths, prompts, app config
├── core/
│   ├── db_manager.py          # SQLite CRUD, progress tracking
│   ├── ai_controller.py       # Async wrappers for Ollama/Whisper/Kokoro
│   └── lesson_engine.py       # Lesson tree, question generation, scoring
├── gui/
│   ├── main_window.py         # Tab-based main window
│   ├── lesson_widget.py       # Lesson module UI
│   ├── voice_chat_widget.py   # Push-to-talk chat UI
│   └── progress_widget.py     # Stats, charts, vocabulary
├── data/
│   └── lessons.db             # SQLite database (auto-created)
├── requirements.txt
└── README.md
```

## Iterative Development Plan

### Iteration 1: Project scaffold + DB layer
- Create project structure, `requirements.txt`, `settings.json`
- Implement `DBManager` with tables: `users`, `lessons`, `progress`, `vocabulary`, `activity_log`
- Unit tests for DB operations

### Iteration 2: AI Controller (Ollama + Whisper)
- Implement `AIController` with async QThread workers
- Ollama chat wrapper (lesson mode + roleplay mode)
- Faster-Whisper STT wrapper (audio → text)
- Integration tests with local Ollama instance

### Iteration 3: Lesson Engine
- Implement `LessonEngine` — lesson tree A1→B2, question flow
- AI-based answer evaluation (score 0–100)
- Progress logging to DB

### Iteration 4: GUI — Main Window + Lesson Widget
- PyQt6 main window with tab navigation
- Lesson widget: theory display, input field, score feedback
- Async signal/slot wiring (no GUI freeze)

### Iteration 5: Voice Chat Module
- Push-to-talk (spacebar) with audio recording
- Faster-Whisper transcription pipeline
- AI response + Kokoro TTS playback
- Chat history display

### Iteration 6: Progress & Stats Module
- Vocabulary manager (mark unknown words, review mode)
- Activity calendar (bar chart via PyQtGraph)
- Performance line chart (accuracy over time)
- Streak counter

### Iteration 7: Polish + Packaging
- Settings UI for model selection, prompts
- .spec file for PyInstaller packaging
- Final integration testing

## Key Technical Decisions
- **GUI Framework**: PyQt6 (per TZ)
- **AI Model**: Llama-3-8B-Instruct via Ollama (Q4_K_M)
- **STT**: Faster-Whisper small, int8 on CPU
- **TTS**: Kokoro-82M via ONNX runtime
- **Charts**: PyQtGraph (lighter than Matplotlib for PyQt)
- **Threading**: QThread for all AI/STT/TTS calls

## Verification
- Each iteration ends with unit/integration tests
- GUI must remain responsive during all AI operations
- SQLite must persist data across app restarts
- All AI calls must be configurable via `settings.json`
